Why Bookmarktivity?

Bookmark collections grow across projects and profiles. Bookmarktivity gives them a focused desktop workspace: combine only the profiles you enable, see where every item came from, and find a result through search, folders, or both.

Microsoft Edge, Google Chrome, and Brave are local browser sources. The app reads enabled local profiles and does not edit browser bookmark files.

Features available now First usable implementation

Layered filtering

Search by name, URL, or immediate folder name. Add a second “within results” query to narrow the current set.

Folder scope

Search a selected folder with descendants or limit results to its direct contents.

Expressive queries

Use field prefixes, quoted phrases, AND/OR, fuzzy text matching, or a bounded regex mode.

Keyboard navigation

Traverse folder and result trees, open a bookmark, copy its URL, or move focus with shortcuts.

Profiles with provenance

Enable individual browser profiles. Every result keeps its browser, profile, and folder path visible.

Focused workspace

Sort results, highlight matches, show folder counts, resize sidebars, and switch between light and dark themes.

Targeted re-read

Refresh all enabled profiles, one browser source, or one profile while keeping the current query and scope.

Private by design

Bookmark data stays in memory; the browser preview uses synthetic data and the native adapter reads enabled profiles only.

Filtering, including nested filtering

Start with a broad search, choose fields, set a folder scope, and then search within the result set. These layers work together while the active filters remain visible.

ActionWhat it finds
name:"Project plan"The exact phrase anywhere in a bookmark name.
url:docs.example.com AND name:guideBookmarks satisfying both field conditions.
folder:ResearchMatching folders; expand one to browse its contents.
design OR researchItems matching either term.
Search within results: 2026A narrower set from the current search, without replacing it.
Selected folder + direct contentsOnly items directly inside that folder.

Folder-name matching uses the immediate containing folder, while folder scope controls the search location. Invalid query syntax is shown in the results area.

Project status

The first usable desktop implementation is in place. The native app has been compile-checked on macOS. An Apple Silicon DMG and a Windows x64 NSIS installer can be built locally. Windows installation and platform webview behavior still need validation before a public release; Linux packaging remains unvalidated.

Windows test installers are unsigned. The repository contains Windows distribution guidance and manual release preparation notes.

Run locally

Install Node.js 20+ and a Rust toolchain:

npm install
npm run tauri -w @bookmarktivity/desktop -- dev

For a browser-only preview with synthetic bookmarks, run npm run dev.
