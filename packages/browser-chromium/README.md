# Shared Chromium bookmark reader

This Rust crate discovers profile folders within a browser adapter's selected user-data directory and reads `Bookmarks` and `AccountBookmarks` JSON from a selected profile. It assigns source and node IDs that remain distinct across browsers, user-data directories, profiles, and storage files. Encrypted stores are decrypted with the operating system's key (`src/os_crypt.rs`, ADR 0011) and preferred over clear text. If decryption fails, a clear-text copy is loaded with a possible-staleness warning; otherwise the profile read fails. Browser files are never written, and tests use synthetic data.
